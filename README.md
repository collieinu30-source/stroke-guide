# دليل الجلطة الدماغية — Stroke Guide 3D

تطبيق ويب تعليمي ثلاثي الأبعاد بالعربي يشرح الجلطة الدماغية وجلطة المخيخ وتأثير ضغط الدم على القلب. يعمل على الآيفون من المتصفح ويمكن إضافته للشاشة الرئيسية.

**للتثقيف فقط ولا يغني عن الطبيب.**

- تقسيم فصوص الدماغ: أطلس AAL.
